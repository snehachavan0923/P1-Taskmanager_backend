# 🚀 Task Manager Application

A full-stack **Task Manager** application that allows users to efficiently create, manage, and track their daily tasks.

---

## 📌 Overview

This project started as a simple To-Do app and was later enhanced into a more structured **Task Management system**, where users can organize and manage their tasks dynamically.

---

## 🛠️ Tech Stack

* **Frontend:** React + Bootstrap
* **Backend:** Spring Boot
* **Database:** MongoDB

---

## ✨ Features

* ✅ Create new tasks
* 📋 View all tasks
* ✏️ Update/edit tasks
* ✔️ Mark tasks as completed
* ❌ Delete tasks
* 🔄 Full CRUD operations via REST APIs

---

## ⚙️ How to Run

### 🔹 Backend (Spring Boot)

1. Make sure MongoDB is running
2. Navigate to backend folder
3. Run the application

```bash
./mvnw spring-boot:run
```

---

### 🔹 Frontend (React)

```bash
npm install
npm start
```
